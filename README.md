# BLACK 2 THE FUTURE SPORTS TV

A responsive retro-sports streaming interface built with React and Vite. It tunes the supplied YouTube channels through their official uploads playlists; videos are embedded from YouTube and are not copied or rehosted.

Live site: <https://bigmix415.github.io/black-2-the-future-sports-tv/>

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Channel metadata lives in `src/channels.js`. Add or replace a station with its YouTube channel ID and a representative public video ID.
